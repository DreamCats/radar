## 定位

radar = 个人投资者的**专属投研工作台**。
- 数据源：复用老板给的微信投研群消息（同 stock-news）
- 服务对象：**只服务我一个人**——我的关注赛道、我的持仓、我的决策习惯
- 与 stock-news 的根本区别：不追求通用/全链路，追求**专 + 降噪 + 个性化**

## 核心诉求（推断，待确认）

### A. 个性化降噪 `[?]`
- 群白名单：只看我手工挑选的高质量投研群，生活群/作业群直接滤掉
- 赛道/个股关注：按我在乎的方向（如算力、固态电池、半导体…）过滤与高亮
- 来源加权：知名机构/可信发送人的消息优先

### B. 早期信号雷达 `[?]`
- 借鉴老项目「成熟锚点+陌生组合」思想，抢早抢新概念
- 当某个新方向开始在多个群/多人接力时，第一时间提示我

### C. 工作台呈现形态 `[?]`
- 你最早说的是「工作台」——倾向一个能「看」的界面（Web dashboard？）
- 还是延续 CLI？还是 CLI + 推送到手机？
- **待确认**：见 04-open-questions

### D. 个人决策复盘 `[?]`
- 记录我自己的判断/操作，与消息信号对照，复盘准不准
- （可选）是否引入行情数据做胜率回测

## 明确不做（草案）
- 不做面向他人的策略快报投递（那是 stock-news 的活）
- 不追求大而全的 pipeline 编排
- 不重复造 stock-news 已经做好的轮子

## 技术栈倾向（待定）
- 若延续 Python 生态，可与老项目保持一致（uv/click/pydantic），降低心智负担
- 若要做 Web 看板，需要确认前端方案
