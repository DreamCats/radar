## radar 的设计需求约束

1. **长时间阅读** — 每天盯消息流，护眼优先 → 暗色 / 低对比
2. **数据密集** — 表格、信号流、赛道热度，要 hold 住高信息密度
3. **金融/投研气质** — 涨跌色、专业感
4. **后期要图表/雷达看板** — 清晰语义色 + 可视化友好的中性底

## 决策：Linear + Binance 涨跌色

**主基底 = Linear**
- 极黑底 + 单一薰衣草蓝点缀，信息密度极高、克制耐看，最接近专业投研终端。
- "dense, technical, quietly luxurious" 与「盯消息流 + 数据看板」天然契合。
- 暗色长阅读友好，薰衣草蓝不抢戏，数据是主角。
- 唯一短板：无金融涨跌色 → 用 Binance 补。

**金融扩展 = 借 Binance 涨跌色**
- `market-up #0ecb81`（涨）/ `market-down #f6465d`（跌）
- **铁律：仅作文字/箭头/数值色，绝不做按钮背景**（沿用 Binance 专业用法）
- A 股「红涨绿跌」可整体对调 up/down 映射，色值不变
- `signal-hot #fcd535`（强信号，克制）借自 Binance Yellow

## 备选留档（未选，记录理由）
- **Sentry**：监控仪表盘气质很贴，但青柠+粉的配色对投研偏「告警系统」感，金融语义弱。
- **Binance（纯）**：金融感最强，但黄色用多易显「廉价交易所」，故只取其涨跌色而非整套。
- **Catppuccin（现成）**：最护眼、零成本，但气质偏「对话工作台」而非「数据看板」，金融感最弱。
