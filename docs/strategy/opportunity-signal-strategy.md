# 发酵确认策略

## 一句话说明

发酵确认策略解决的是一个很具体的问题：当某个方向已经开始升温时，投资人不知道它还值不值得继续看。

它原来叫“机会信号策略”。现在把它降级为确认层：它不是负责抢最早的新概念，而是负责判断已经发酵的方向是否还有研究价值。

它不是告诉你“买什么”，而是告诉你“哪些已经升温的方向值得优先确认”。它把微信消息里的热度、来源、主题、股票和历史回测放在一起，先替你做一轮排序。

## 投资人真正遇到的问题

现在 radar 已经有很多离线产物，但这些产物本身还不是答案。

你可能能看到：

- 哪些词最近被提到很多。
- 哪些消息被分类成投资推荐、研究观点、产业变化。
- 哪些主题被聚合出来。
- 哪些来源或板块在 T+5 回测里表现不错。
- 哪些股票被不同人反复提到。

问题是，投资人每天打开网站时，真正想问的不是“数据有哪些”，而是：

- 今天我有限的时间先看哪 3 个方向？
- 这个方向是刚开始升温，还是已经全市场都在说？
- 是单个群里有人喊，还是多个来源都在讨论？
- 它有没有对应股票？这些股票历史推荐后的表现怎么样？
- 这里面有没有风险词、反证或者过热迹象？

发酵确认策略就是为了回答这些问题。

## 策略要产出的结果

第一版产出三类东西。

### 1. 今日确认 Top3

放在总览 tab。

它的作用是让你打开网站后不用先逛一圈，直接看到今天最值得优先点开的方向。

它回答：

- 今天最值得先看的机会是什么？
- 它为什么排在前面？
- 它是高热度、强拐点，还是回测表现好？

### 2. 发酵机会列表

放在策略 tab。

它是 Top3 的完整版本，每个机会都带解释和关键指标。

它回答：

- 这个主题最近 7 天是不是明显升温？
- 有多少人、多少群在讨论？
- 投资推荐、研究观点、产业变化这些高价值消息占比高不高？
- 有没有催化词，比如涨价、订单、供需改善、政策、业绩？
- 有没有风险词，比如拥挤、下修、砍单、监管、分歧？
- 对应的 T+5 胜率和平均超额收益怎么样？

### 3. 来源质量和优质股票池

也放在策略 tab。

来源质量是为了回答：哪些来源最近提到的方向更值得重视。

优质股票池是为了回答：哪些股票在消息和回测里同时有证据，值得进一步打开行情或公告看一眼。

这里的“优质”不是买入建议，只表示它在当前数据里更值得优先研究。

## 核心思路

这套策略的核心不是预测股价，而是做“注意力分配”。

如果一个方向满足下面几件事，它就更值得排在前面：

- 最近突然被更多人讨论。
- 不是一个人或一个群在喊，而是多个来源都在提。
- 消息内容更偏投资推荐、研究观点、产业变化，而不是闲聊。
- 有清晰催化，比如涨价、订单、供需改善、政策变化、业绩改善。
- 能映射到股票或板块，不是只有模糊概念。
- 历史上类似推荐在 T+5 有正超额或较高胜率。
- 风险词不多，或者至少风险还没有压过机会。

反过来，如果一个方向只是很热，但证据质量弱、风险词多、样本太少，或者讨论已经过度扩散，它不应该被简单排到最前面。

## 第一版怎么打分

第一版是规则评分，不接新的 LLM 流程。

它主要看六类信号。

### 1. 热度拐点

看最近 7 天相对前一段时间是不是明显升温。

投资含义：刚开始升温的方向，可能比已经到处都在说的方向更值得继续确认。

### 2. 讨论广度

看有多少发送人、多少群在讨论。

投资含义：多个来源都在提，比单点消息更像一个正在扩散的线索。

### 3. 消息质量

看高价值分类占比，比如投资推荐、研究观点、产业变化。

投资含义：同样是热度，研究和推荐比闲聊更有投研价值。

### 4. 催化与风险

统计催化词和风险词。

投资含义：有催化但风险词不多，才更适合作为今日优先研究对象。

### 5. 回测表现

关联已有的 T+5 胜率、平均收益、平均超额收益、样本数。

投资含义：如果某个来源、股票或板块过去被提到后经常跑赢，今天的新信号就更值得重视。

### 6. 拥挤和样本惩罚

热度过高但质量不够，或者样本太少，都要降权。

投资含义：策略不能只追热点，也不能因为一两条消息就给太强结论。

## 注意力标签怎么理解

策略不会输出“买入”或“卖出”，只输出注意力标签。

- 重点关注：分数高，样本和可靠性也够，今天优先打开看。
- 继续验证：有线索，但证据还不够完整，适合继续看原始消息和后续消息。
- 风险升高：机会存在，但风险词、反证或拥挤度已经明显，需要谨慎。
- 样本不足：可能有价值，但消息太少，不能下太强判断。
- 过度扩散：讨论很多，但可能已经太热，不适合只因为热度继续追。

## 一个具体例子

假设今天策略里出现“MLCC”。

如果它排在前面，可能是因为：

- 最近 7 天 MLCC 消息明显比前一段多。
- 不止一个群在聊，也不止一个发送人在提。
- 消息里有“涨价”“供需改善”“订单”等催化词。
- 关联到的股票在历史 T+5 回测里平均超额为正。
- 风险词不多，或者风险还没有压过催化。

投资人看到这个结果后，不应该直接买 MLCC 相关股票。

更合理的动作是：

- 点进策略 tab 看它为什么上榜。
- 看相关股票和主要来源。
- 回到原始消息或整理结果里看证据。
- 再结合行情、公告、估值、位置判断是否值得继续研究。

## 当前使用的数据

第一版只读已有离线产物，不新增新的 LLM 流程。

主要使用：

- `messages`：消息时间、群、发送人。
- `message_classifications`：消息分类、置信度、高价值类型。
- `message_anchors`：股票、概念、行业、主题 anchor。
- 聚合主题结果：主题、催化、风险、行动分。
- 推荐回测结果：T+5 胜率、平均收益、平均超额、样本数。
- 股票映射结果：把主题或 anchor 尽量落到可研究股票上。

## 为什么第一版不接新 LLM

因为当前已经有不少离线产物没有被充分使用。

第一版优先做三件事：

- 把已有产物串起来。
- 用规则产出稳定、可解释的排序。
- 通过 UI 验证这个排序对每天看盘是否真的有用。

如果后续发现某些关键判断必须读原文、抽取更复杂的因果，才考虑新增 LLM 流程。

## 这套策略不解决什么

它不解决：

- 什么时候买。
- 买多少仓位。
- 什么时候卖。
- 是否一定能赚钱。
- 消息真假验证。
- 财务、估值、技术面完整分析。

它只负责把消息源里的投研线索变成更高价值的关注顺序。

## 和早期概念雷达的关系

这套策略不负责解决“概念刚提出时能不能提前准备”的问题。

后续更高优先级的策略是 [早期概念雷达策略](./early-concept-radar-strategy.md)。它负责找种子概念、首次绑定个股和早期扩散；本策略负责在概念已经升温后做二次确认、来源质量判断、回测验证和追高风险提示。

理想链路是：

- 早期概念雷达发现新概念。
- 早期概念雷达记录首次绑定股票。
- 后续出现跨来源扩散后，进入发酵确认策略。
- 如果已经过热，本策略只做复盘，不建议再按新机会处理。

## 后续可以增强的方向

后续可以继续拆更多策略，但每个策略都应该先讲清楚投资问题。

可能方向：

- 早期概念雷达策略：找刚开始跨群传播、还没过热的新概念和首次绑定股票。
- 来源跟随策略：重点跟踪历史回测更有效的来源。
- 股票共识策略：找多个来源共同指向、但还没拥挤的股票。
- 风险预警策略：识别热度上升但风险词同步变多的方向。
- 主题到股票策略：把主题热度稳定映射到可研究股票池。
- 事件催化策略：围绕涨价、订单、政策、业绩预告等事件做机会排序。

这些策略可以复用当前的消息、分类、anchor、主题和回测产物；只有当现有产物回答不了问题时，再考虑新增离线任务或 LLM。
