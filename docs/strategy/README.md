# 策略文档

这个目录用来沉淀 radar 的策略能力。

这里说的“策略”不是完整交易策略，也不是自动买卖系统。它更像投资人每天打开工作台时的注意力排序器：用已经离线处理好的微信消息、主题、anchor、回测和股票映射，回答“今天先看什么、为什么值得看、下一步应该深挖哪里”。

## 当前策略

- [机会信号策略](./opportunity-signal-strategy.md)：把分散的消息和离线产物，压缩成“今日机会 Top3”、完整机会候选、来源质量和优质股票池。

## 后续新增策略怎么写

每个策略单独一份文档，至少讲清楚：

- 它站在投资人视角解决什么问题。
- 它的核心判断思路是什么。
- 它使用哪些现有离线产物，是否需要新的 LLM 流程。
- 它输出什么，投资人打开网站后应该怎么用。
- 它不解决什么，避免被误用成买卖建议。

先把这些问题讲清楚，再决定是否实现 UI 或新增离线任务。
