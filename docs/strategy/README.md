# 策略文档

这个目录用来沉淀 radar 的策略能力。

这里说的“策略”不是完整交易策略，也不是自动买卖系统。它更像投资人每天打开工作台时的注意力排序器：用已经离线处理好的微信消息、主题、anchor、回测和股票映射，回答“今天先看什么、为什么值得看、下一步应该深挖哪里”。

## 当前策略

- [早期概念雷达策略](./early-concept-radar-strategy.md)：优先研究的新策略，目标是在概念刚被提出、还没有充分发酵时，提前锁定概念和首次绑定个股。
- [发酵确认策略](./opportunity-signal-strategy.md)：原“机会信号策略”，现在降级为确认层。它负责判断已经升温的方向是否仍值得看，不能单独解决追高风险。

## 当前优先级

radar 后续策略不做纯技术面，也不追公开已知消息。核心是消息面，技术面只作为位置、涨幅、回撤和过热过滤。

第一优先级是验证“早期概念雷达”是否真的有提前量；第二优先级才是继续优化“发酵确认策略”的胜率。

## 后续新增策略怎么写

每个策略单独一份文档，至少讲清楚：

- 它站在投资人视角解决什么问题。
- 它的核心判断思路是什么。
- 它使用哪些现有离线产物，是否需要新的 LLM 流程。
- 它输出什么，投资人打开网站后应该怎么用。
- 它不解决什么，避免被误用成买卖建议。

先把这些问题讲清楚，再决定是否实现 UI 或新增离线任务。
