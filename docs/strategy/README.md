# 策略文档

这个目录用来沉淀 radar 后续的“机会信号策略”。

这里的策略不是完整交易系统，也不是自动下单建议。它更像每天打开投研工作台时的一层决策排序：基于离线任务已经产出的消息分类、主题聚合、anchor、推荐回测、股票映射等数据，回答“今天优先看什么、哪些主题值得深挖、哪些股票可能更有价值”。

## 本次策略：机会信号策略

### 目标

把大量微信消息和离线分析结果压缩成投资人每天能快速消费的机会列表。

第一版目标很明确：

- 在总览里给出“今日机会 Top3”。
- 在策略 tab 里给出完整机会候选、来源质量、优质股票池。
- 每个机会都能解释为什么值得看，而不是只给一个黑盒分数。
- 先不接新的 LLM 流程，优先榨干现有离线产物。

### 解决什么问题

当前 radar 已经有很多离线产物：

- 原始消息。
- 消息分类。
- anchor 命中。
- 聚合主题。
- 推荐胜率回测。
- 股票和板块映射。

但这些产物如果只是分散成表格和图，投资人仍然要自己判断：

- 哪些主题正在升温？
- 哪些升温不是噪音？
- 哪些来源历史上更靠谱？
- 哪些股票既被提到，又有相对好的 T+5 表现？
- 哪些信号已经太拥挤，反而要谨慎？

机会信号策略要做的是把这些判断前置，产出一个可排序、可解释、可继续深挖的列表。

### 第一版思路

第一版是规则评分，不是模型生成。

核心信号包括：

- 热度拐点：最近 7 天消息量相对前一窗口是否明显上升。
- 讨论广度：是否有多个发送人、多个群在讨论，降低单点噪音。
- 消息质量：分类里投资推荐、研究观点、产业变化占比是否更高。
- 催化与风险：从已结构化信息里统计涨价、供需、订单、风险、拥挤等词。
- 回测表现：关联 T+5 胜率、平均超额收益和样本数。
- 拥挤惩罚：消息过多但有效证据不足时降低优先级。
- 样本惩罚：样本太少时不直接给“重点关注”。

最终输出不是“买入/卖出”，而是注意力分配：

- 重点关注：分数高、样本和可靠性足够。
- 继续验证：有信号，但还需要看证据。
- 风险升高：风险词或反证偏多。
- 样本不足：线索可能有价值，但证据太少。
- 过度扩散：讨论很热，但可能已经拥挤。

### 当前使用的数据

第一版只读现有表和离线结果，不新增新的 LLM 链路。

主要依赖：

- `messages`：消息时间、群、发送人。
- `message_classifications`：消息分类、置信度和价值类型。
- `message_anchors`：股票、概念、行业、主题 anchor。
- 推荐回测结果：T+5 胜率、平均收益、平均超额、样本数。
- 聚合主题结果：主题、催化、风险、行动分。

如果后续某个策略需要新字段或新 LLM 产物，再单独评估，不默认把所有策略都变成新的 LLM pipeline。

### 当前 UI 产物

总览 tab：

- 展示“今日机会 Top3”。
- 让投资人一眼看到今天最值得打开的方向。

策略 tab：

- 今日机会：完整候选列表和解释。
- 来源质量：哪些来源近期信号质量更好。
- 优质股票池：由回测事件聚合出的股票候选，明确标注“非买入建议”。

### 边界

这个策略不做：

- 自动交易。
- 仓位建议。
- 止盈止损。
- 预测股价。
- 对消息真实性做最终判断。

它只做一件事：帮个人投资者把有限注意力放到更可能有价值的消息、主题和股票上。

### 后续可以继续讨论的策略

后续每个策略都应该继续写进这个目录，至少说明目标、输入、评分思路、输出和边界。

可能的方向：

- 早期扩散策略：找刚开始跨群传播、还没过热的主题。
- 来源跟随策略：识别历史回测更有效的来源和分析师。
- 股票共识策略：找多个来源共同指向、但消息仍不拥挤的股票。
- 风险预警策略：识别高热度但风险词、反证、拥挤度同步上升的方向。
- 主题到股票策略：从主题热度映射到可跟踪股票池。
- 事件催化策略：围绕涨价、订单、政策、业绩预告等事件做排序。

### 讨论原则

后续讨论策略时，先问三个问题：

- 这个策略帮我节省什么判断成本？
- 它使用哪些已经存在的离线产物？
- 它的输出能不能直接改变我今天打开网站后的关注顺序？

如果答案不清楚，先不要做成 UI，也不要新增复杂链路。
