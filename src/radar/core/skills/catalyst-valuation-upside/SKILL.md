# 催化估值线索空间测算

用于把一份 Radar 催化估值线索报告二次加工成“还有多少空间、是否已经定价、下一步盯什么”的研究任务。默认假设报告中的原文证据可能成立，但必须把已确认事实、基于假设的推断、仍需验证的条件分开。

## 工作流

1. 先从页面上下文获取 `report_id`，调用 `radar_get_catalyst_valuation_report` 读取本地结构化报告。不要依赖公网报告 URL 抓网页正文。
2. 对每个标的先补当前市值数据：优先用 `radar_get_stock_price_history` 查询 `daily_basic` 最近交易日的 `total_mv`，必要时用 `radar_get_realtime_quote` 补盘中价格和涨跌幅。查不到就标“当前市值缺口”，不要编造。
3. 从报告证据中抽取目标市值、利润、产能、价格、PE、市占率、订单、渗透率等核心数字。
4. 用第一性原理重算目标市值区间：资源品优先用“产能 x 价差 x 净利率 x PE”，制造/电子优先用“收入 x 净利率 x PE”，平台型公司按业务分部加总。
5. 计算剩余空间：`(目标市值 / 当前市值 - 1) x 100%`。区间目标必须给区间空间。
6. 判断定价状态：`显著空间`、`有空间但需验证`、`基本反映`、`已超目标`、`严重透支`。
7. 做交叉验证：同一标的如果在多份报告或多条证据中重复出现，提升跟踪优先级；如果只有单条小作文，降低置信度。
8. 输出机会排序，不输出买卖、仓位、确定性收益或“必涨”措辞。

## 输出结构

```text
结论：一句话说明这份报告里真正有空间的标的数量，以及最需要优先跟踪的标的。

## 空间测算总表
| 排名 | 标的 | 当前市值 | 目标市值 | 剩余空间 | 状态 | 确定性 | 关键验证 |

## 重点标的拆解
每个重点标的按：
- 第一性原理公式
- 关键数字来源
- 当前市值对比
- 触发升级条件
- 触发降级条件

## 已充分定价或追高风险
列出当前市值已经接近或超过目标市值的标的，并说明为什么不应只看故事热度。

## 数据缺口
列出没有查到当前市值、目标市值口径不清、证据等级偏低或需要公开来源验证的地方。
```

## 判定规则

- 剩余空间 >= 80% 且核心数字可交叉验证：`显著空间`。
- 剩余空间 30%-80%：`有空间但需验证`。
- 剩余空间 0%-30%：`基本反映`。
- 当前市值超过目标区间上沿：`已超目标`。
- 当前市值超过目标区间上沿 100% 以上：`严重透支`。
- 如果当前市值缺失，不给空间百分比，只给“待补市值后排序”。

## 约束

- 报告 URL 只作为给人打开的参考链接；分析输入以 `radar_get_catalyst_valuation_report` 返回的本地结构化报告为准。
- 不把“目标市值”写成投资建议；所有目标都必须注明“证据成立假设下”。
- 不把短期涨跌幅当作空间测算主因；涨跌幅只用于判断是否已经被市场快速消化。
- 不为了补齐表格而捏造当前市值、PE 或利润率。
- 不把没有单位的数字直接当作亿元或万吨；单位不清要列入数据缺口。
