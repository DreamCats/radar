# 可控核聚变 / 核电设备产业链学习页

> 草案版本：2026-06-20  
> 目标用户：产业链学习新手 / A 股主题研究入门  
> 证据原则：先分清成熟核电和长期聚变，再看项目核准、设备订单、工程交付、聚变装置采购，最后回到收入、毛利和现金流。

## 一句话先懂

核电和可控核聚变经常被市场放在一起，但它们不是一条完全相同的投资链。

**核电**是已经商业化的低碳基荷电源，看核准、开工、设备招标、工程建设、运营发电和检维修。  
**聚变**是未来能源技术期权，还处在科研装置和工程验证阶段，看超导磁体、偏滤器、第一壁、真空低温、微波加热和大科学装置项目。

这条链可以按五步学：

1. **能源约束**：AI 用电、电气化和双碳目标提高稳定低碳电源需求。
2. **核电核准**：项目核准和开工决定核岛、常规岛、阀门、管材和工程订单。
3. **设备拆解**：核岛主设备、常规岛汽轮机发电机、核级阀门泵和核级管材分别验证。
4. **聚变卡点**：超导线材、磁体、偏滤器第一壁、真空低温和微波加热才是更核心的聚变部件。
5. **财务兑现**：订单、交付、收入占比、毛利、应收、存货和现金流决定是真受益还是概念暴露。

## 为什么现在要看

核能现在有两条线同时被市场关注：

- **核电线**：核电项目持续核准，带动主设备、阀门、管材、工程建设和运营服务。
- **聚变线**：可控核聚变进入未来产业和新型能源体系叙事，中国聚变能源公司、BEST、CRAFT、ITER、EAST 等项目让核心部件有了验证场景。
- **资金线**：主题热度上来后，市场容易把“核电设备订单”和“聚变远期期权”混在一起，需要用证据拆开。

所以研究这条产业链，第一件事不是背股票，而是先判断公司到底在：

- 成熟核电设备链；
- 核电工程和运营链；
- 聚变实验装置核心部件链；
- 还是只有参股、概念或远期布局。

## 学习路径

### 1. 先看能源约束

核能的底层逻辑是稳定低碳电力。风光很重要，但有波动性；AI 算力、电气化和制造业用电又提高了对稳定电源的要求。

新手先问：

- 核电核准节奏有没有持续？
- 电力负荷和 AI 用电是否强化稳定电源需求？
- 政策支持的是成熟核电、未来聚变，还是两者都提到？

### 2. 再分清核电和聚变

核裂变核电已经商业化，能在财报里看到运营收入、设备订单、工程合同和检维修。可控核聚变还没有商业化发电，短中期更多体现为科研装置、示范工程和关键设备材料采购。

可以简单记：

- **核电**：现在能挣钱，重点看订单和交付。
- **聚变**：未来空间大，重点看项目验证和技术卡点。
- **参股聚变平台**：代表远期布局，不等于短期利润。

### 3. 拆开核电设备

核电项目核准后，会拉动多个设备环节：

- **核岛主设备**：反应堆压力容器、蒸汽发生器、稳压器、主泵、堆内构件。
- **常规岛设备**：汽轮机、发电机、汽水分离再热器和辅机。
- **核级阀门 / 泵**：控制介质流动、安全隔离和系统运行。
- **核级管材 / 特种材料**：耐腐蚀、耐高温、高一致性和核级认证。
- **核电工程建设**：土建、安装、调试、核岛施工和工程管理。

这里最重要的验证不是“有没有核能概念”，而是有没有核级资质、项目订单、交付台套和收入确认。

### 4. 进入聚变卡点

聚变难点在于让高温等离子体长期稳定运行。对应到产业链，核心卡点集中在：

- **超导磁体 / 超导线材**：托卡马克需要强磁场约束等离子体。
- **偏滤器 / 第一壁材料**：直接面对高温等离子体，承受极端热负荷和辐照环境。
- **真空低温 / 微波加热**：维持实验装置运行环境，并帮助等离子体加热。
- **氚增殖包层 / 燃料循环**：偏远期，是商业化闭环的重要难题。
- **ITER / CRAFT / BEST / EAST**：这些项目是材料和设备从实验室走向工程化的验证入口。

对小白来说，聚变研究最容易踩的坑是：把“参与聚变概念”直接等同于“商业化发电收入”。目前更现实的收入来自项目制订单、样件、验收和工程交付。

### 5. 最后看财务兑现

核能主题最终要回到财报。

- 核电设备看新签订单、在手订单、交付台套、收入占比和毛利。
- 核电工程看新签合同、工程收入、回款和现金流。
- 核电运营看装机、发电量、利用小时、电价和核能多用途服务。
- 聚变部件看是否进入 ITER、EAST、CRAFT、BEST，是否有中标、验收、交付和收入确认。
- 参股型公司看投资金额、被投公司阶段和风险提示，不能直接外推短期业绩。

## A 股映射怎么读

先分角色，而不是先背股票：

- **核能装备龙头**：上海电气。核岛、常规岛和聚变大科学装置部件都有一手披露，适合作为入口验证。
- **核电主设备龙头**：东方电气。偏成熟核电设备主线，看核电订单、核岛和常规岛设备交付。
- **核电运营龙头**：中国核电。验证核电装机、发电量、核能多用途和聚变远期投资。
- **核电工程建设龙头**：中国核建。看核电工程合同、收入、回款，也有 ITER 工程验证线索。
- **聚变超导材料龙头**：西部超导。看 NbTi、Nb3Sn、高温超导材料和磁体项目交付。
- **偏滤器和第一壁材料龙头**：安泰科技。看钨铜复合材料、偏滤器、第一壁和 EAST、CRAFT、BEST 项目。
- **真空 / 微波 / 核工业设备候选**：国光电气。逻辑相关，但要特别注意订单延后、项目设计变更和业绩波动。
- **核级阀门候选**：江苏神通、中核科技。看核电阀门订单、在手订单、产能和毛利。
- **核级管材候选**：久立特材。先按核能管材和高端材料看，聚变弹性需要继续补一手证据。
- **参股型远期布局**：浙能电力。参股中国聚变能源代表长期布局，不是短期设备弹性。

## 最容易踩的坑

1. **把核电和聚变混成一个确定性**：核电能财务验证，聚变还在工程验证。
2. **把参股聚变平台当短期利润**：参股更像远期技术期权。
3. **只看核准数量，不看交付周期**：核准、招标、交付、收入确认之间有明显滞后。
4. **把普通材料公司当聚变材料公司**：必须看超导、第一壁、偏滤器、真空低温等具体项目证据。
5. **只看中标不看现金流**：核能项目周期长，应收、存货和回款压力同样重要。

## 后续跟踪指标

- 年度核电核准台数、开工节奏和在建机组。
- 核岛、常规岛主设备订单和交付台套。
- 核级阀门、泵、管材和特种材料订单。
- CRAFT、BEST、ITER、EAST 等聚变项目采购、验收和交付。
- 聚变相关收入占比、毛利、应收、存货和经营现金流。
