# 创新药 / ADC / 双抗出海产业链学习页

> 草案版本：2026-06-20  
> 目标用户：产业链学习新手 / A 股主题研究入门  
> 证据原则：先看临床价值，再看审批和商业化，最后看收入、现金流和失败风险。

## 一句话先懂

创新药不是“药名越新越好”，而是看它有没有解决真实临床问题，临床数据够不够硬，能不能获批并卖出去，最后能不能让公司收入、利润和现金流变好。

这条链可以按六步学：

1. **需求和支付**：病人为什么需要新药，医保和商保能不能支持。
2. **靶点和平台**：药到底通过什么机制解决问题，ADC、双抗、小分子只是工具。
3. **临床验证**：从临床前到 I/II/III 期，证据逐步变强，失败成本也变高。
4. **注册和生产**：临床数据之外，还要有审评审批、CMC 和稳定供应。
5. **BD 出海和销售**：海外授权验证资产价值，商业化销售验证医生和患者是否买单。
6. **财务和风险**：最终回到首付款、里程碑、销售收入、毛利、研发费用、现金流和失败风险。

## 为什么现在要看创新药

创新药的主线来自三层变化：

- **临床端**：肿瘤、自免、罕见病等领域仍有大量未满足需求。
- **技术端**：ADC、双抗、多抗、小核酸、蛋白降解等平台让国产药企能做出更复杂的资产。
- **商业端**：License-out、海外获批、医保目录和商保创新药目录，让资产价值有了更清晰的外部验证路径。

但这条产业链最容易被误读。总交易金额不等于已经到账，进入 I 期不等于快上市，获批也不等于一定卖爆。

## 学习路径

### 1. 先看未满足临床需求

真正的创新药机会来自患者痛点。比如现有治疗效果不好、副作用大、复发率高、没有标准治疗，或者患者用药负担过重。

小白先问三个问题：

- 这个病有没有明确患者群？
- 现有治疗有什么问题？
- 新药解决的是疗效、安全性、便利性还是支付问题？

### 2. 再看靶点和技术平台

ADC、双抗这些词本身不是结论。它们只是药物设计方式：

- **ADC**：抗体负责识别目标，连接子负责稳定释放，载荷负责杀伤。
- **双抗 / 多抗**：一个药物同时识别两个或多个靶点，可能提高疗效，也可能增加毒性和制造难度。
- **小分子 / 抗体 / 小核酸 / 蛋白降解剂**：不同疾病和靶点会选择不同形式。

真正要看的不是平台名字，而是临床数据、适应症、竞品对比和安全窗。

### 3. 进入临床证据

创新药从故事变成事实，主要靠临床试验：

- **I 期**：安全性和剂量，不能简单理解为快上市。
- **II 期**：初步有效性，市场会开始重估资产价值。
- **III 期**：注册关键证据，成功后才有较强获批基础。

看临床数据时，不只看“有效”，还要看样本量、主要终点、对照组、适应症、竞品数据和不良反应。

### 4. 看审批、医保和生产

药品商业化不是临床结束就完成。还要经历：

- NMPA / FDA / EMA 受理和获批。
- 医保目录、商保创新药目录、医院准入。
- CMC 工艺、质量体系、验证批和商业化生产。

复杂药物如 ADC、双抗、生物药，对生产放大和质量控制要求更高，所以 CDMO、CMC 也是产业链重要环节。

### 5. 看 BD 出海和商业化销售

**License-out** 是外部验证，但要拆开看：

- **首付款**：确定性最高，通常最能改善现金流。
- **里程碑**：临床、注册、销售达到条件才触发。
- **销售分成**：最远期，依赖海外商业化成功。

商业化销售则要看单品收入、毛利率、销售费用率、医保准入、医院覆盖和竞品压力。

## A 股映射怎么读

这条链的公司大致分四类：

- **全球商业化验证**：如百济神州，看核心产品全球销售和利润兑现。
- **平台型创新药企**：如恒瑞医药，看多平台、多管线、获批和商业化能力。
- **ADC / 双抗 / BD 出海样本**：如百利天恒、科伦药业、荣昌生物，看关键资产临床数据、授权、获批和销售。
- **研发生产服务端**：如药明康德、泰格医药、凯莱英、美迪西，看订单、项目数量、产能利用率和行业研发活跃度。

服务端公司不是创新药权益公司。它们受益于研发和生产外包，但通常不享有单个药品全球销售的巨大上行。

## 最容易踩的坑

1. **把总交易额当现金到账**：BD 总金额里大量是未来里程碑。
2. **把 I 期当快上市**：多数项目还要经历漫长的 II/III 期和审批。
3. **只看概念名词**：ADC、双抗、小核酸只是路线，关键是数据。
4. **只看获批**：获批后还要看医保、进院、医生处方和销售费用。
5. **把 CXO/CDMO 当创新药资产**：服务商看订单和产能，不看药品权益上行。

## 后续跟踪指标

- 关键临床数据读出：ASCO、ESMO、AACR、公司公告。
- License-out：首付款、里程碑、权益区域、合作方进度。
- 注册审批：NMPA/FDA/EMA 受理、优先审评、获批。
- 支付环境：医保目录、商保创新药目录、支付范围。
- 财务兑现：核心产品销售、毛利率、销售费用率、经营现金流。
- 服务端景气：CXO/CDMO 新签订单、在手订单、PPQ 验证批和商业化项目。
